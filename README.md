# 🧠 Mental Health Website

เว็บไซต์ให้ความรู้และส่งเสริมความเข้าใจเกี่ยวกับ **สุขภาพจิต (Mental Health)** ออกแบบมาเพื่อให้ผู้ใช้งานสามารถเข้าถึงข้อมูลเกี่ยวกับสุขภาพจิต การดูแลตนเอง และแหล่งข้อมูลที่เป็นประโยชน์ได้ง่าย ผ่านการออกแบบเว็บไซต์ที่เรียบง่ายและใช้งานง่าย

🔗 **Live Demo:** https://9superbob.github.io/Mental_Health-66/

---

## 📌 About The Project

**Mental Health Website** เป็นโปรเจกต์เว็บไซต์ที่พัฒนาขึ้นเพื่อรวบรวมและนำเสนอข้อมูลเกี่ยวกับสุขภาพจิตในรูปแบบที่เข้าใจง่าย โดยให้ความสำคัญกับการจัดวางเนื้อหา การนำทางเว็บไซต์ และ Responsive Design เพื่อให้สามารถใช้งานได้ทั้งบนคอมพิวเตอร์ แท็บเล็ต และอุปกรณ์มือถือ

เว็บไซต์ประกอบด้วยเนื้อหาและเครื่องมือที่ช่วยให้ผู้ใช้งานสามารถเรียนรู้เกี่ยวกับสุขภาพจิต รวมถึงแนวทางในการดูแลสุขภาพจิตของตนเอง

---

## ✨ Features

* 🏠 **Home Page** — แนะนำเว็บไซต์และเนื้อหาที่เกี่ยวข้องกับสุขภาพจิต
* 📚 **Mental Health Articles** — รวบรวมบทความและข้อมูลเกี่ยวกับสุขภาพจิต
* 🧠 **Understanding Mental Health** — ให้ความรู้และสร้างความเข้าใจเกี่ยวกับสุขภาพจิต
* 🛠️ **Mental Health Toolkit** — รวมแนวทางและเครื่องมือสำหรับการดูแลสุขภาพจิต
* 💡 **Helpful Resources** — แนะนำข้อมูลและแหล่งความช่วยเหลือที่เกี่ยวข้อง
* 📱 **Responsive Design** — รองรับการแสดงผลบน Desktop, Tablet และ Mobile

## 🛠️ Technologies

* **HTML5** — ใช้สำหรับสร้างโครงสร้างและเนื้อหาของเว็บไซต์
* **CSS3** — ใช้สำหรับออกแบบ Layout, Typography และ Styling
* **Bootstrap 5** — ใช้สำหรับ Responsive Layout และ UI Components

## 🎨 Design & Development

ในการพัฒนาเว็บไซต์ให้ความสำคัญกับ

* **User-Friendly Interface** — ออกแบบให้ผู้ใช้งานสามารถเข้าใจเนื้อหาและใช้งานเว็บไซต์ได้ง่าย
* **Responsive Design** — ปรับ Layout ให้เหมาะสมกับขนาดหน้าจอที่แตกต่างกัน
* **Content Organization** — จัดหมวดหมู่ข้อมูลให้เป็นระเบียบและสามารถเข้าถึงได้สะดวก
* **Consistent Design** — ใช้รูปแบบของ Typography, Spacing และ Components ให้มีความสอดคล้องกัน
* **Accessibility** — พยายามออกแบบให้เนื้อหาอ่านง่ายและเข้าถึงได้ง่ายสำหรับผู้ใช้งาน
