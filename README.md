# 🧠 Mental Health Website

A responsive mental health website designed to provide users with accessible information and resources related to mental health and emotional well-being.

🔗 **Live Demo:** https://9superbob.github.io/Mental_Health-66/

---

## 📖 About The Project

Mental Health is a web-based project created to provide users with an easy and accessible way to learn about mental health.

The website focuses on presenting mental health information through a simple and user-friendly interface. It includes educational content and self-assessment resources that allow users to learn more about their mental well-being.

This project was developed as part of my university coursework and helped me improve my skills in front-end web development, responsive web design, and user interface implementation.

---

## ✨ Features

- 🧠 Mental health educational content
- 📝 Self-assessment section
- 📚 Mental health resources and information
- 📱 Responsive design for different screen sizes
- 🎨 Clean and user-friendly interface
- 🧭 Simple navigation between pages and sections

---

## 🛠️ Technologies Used

- HTML5
- CSS3

- Bootstrap 5
